Transform safety

Each box carries an inline transform: rotate(6deg), which is what Tailwind v3 emits for rotate-3. The first three keep it: that is what the individual translate / scale / rotate properties buy. tm-unfold is the counter-example and loses it — it scales before it translates, which the individual properties cannot express, so it keeps the shorthand and is documented as an exception.
